# YouTube Compatibility Layer

YouTube の DOM は頻繁に変わる。**壊れる箇所をここに局所化する**のが目的。

| ファイル群 | 対象 |
|---|---|
| `common/` | セレクタ定義・SPA ナビゲーション検知（`yt-navigate-finish`）・共通ユーティリティ |
| `layout/` | コメント欄の横移動、サイドバーモード、ホーム/検索のレイアウト |
| `filters/` | チャンネルブロック、視聴済み非表示、検索/関連/ホームからの除外 |
| `player/` | 終了画面カード、オーバーレイ、Shorts を通常プレイヤーで開く |
| `comments/` | コメント欄・固定コメントの制御 |
| `shorts/` | Shorts 棚の非表示・リダイレクト |
| `compatibility/` | YouTube 側変更への追従パッチ、セレクタのフォールバック |

**セレクタは `common/` に集約し、他のファイルは直接 CSS セレクタを書かない。**
YouTube が変わったとき `common/` の 1 ファイルを直せば全体が復旧する構造にする。

低評価数表示は外部 API に依存するため `filters/` 等とは分離し、
API 停止時も他機能に影響しない独立モジュールとして実装する。
