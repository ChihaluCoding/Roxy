# Rules

Script Engine が読み込むルール集。**ここに 1 ファイル足すだけで機能が増える**のが狙い。
Firefox 本体へのハードコードは避け、設定 UI のトグルと pref で ON/OFF する。

| ディレクトリ | 内容 |
|---|---|
| `builtin/` | 汎用プリセット（選択禁止解除・右クリック解除・ダークモード強制など） |
| `youtube/` | YouTube Compatibility Layer。DOM 変更による破損をここに閉じ込める |
| `user-css/` | 同梱するデフォルト CSS |

ルールは 1 ファイル 1 機能。ヘッダに UserScript 互換メタデータを持たせ、
内蔵ルールとユーザールールを同じパーサで扱えるようにする。

ユーザーが作成したルールはプロファイル内（`merlin/rules/`）に保存し、ここには置かない。
